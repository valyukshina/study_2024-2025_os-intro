# Ответы на контрольные вопросы
1. Дайте краткую характеристику режимам работы редактора vi.  
Ответ: Командный режим — используется для ввода команд (удаление, копирование, перемещение и т. д.). В этом режиме нажатие клавиш интерпретируется как команды. Режим вставки — позволяет вводить текст. Переход в него осуществляется командой i. Режим последней строки — активируется нажатием :, позволяет вводить сложные команды (сохранение, поиск, замена, настройки и т. д.).  

2. Как выйти из редактора, не сохраняя произведённые изменения?  
Ответ:В командном режиме ввести :q!  

3. Назовите и дайте краткую характеристику командам позиционирования.  
Ответ: h, j, k, l — перемещение влево, вниз, вверх, вправо. 0 (ноль) — начало строки, $ — конец строки. gg — первая строка файла, G — последняя строка. Ctrl + F / Ctrl + B — пролистать вперёд/назад на страницу. w, b — перемещение на слово вперёд/назад.  

4. Что для редактора vi является словом?  
Ответ: Последовательность букв, цифр и подчёркиваний (A-Za-z0-9_), либо. Любая последовательность символов, кроме пробелов.  

5. Каким образом из любого места редактируемого файла перейти в начало (конец) файла?  
Ответ: Начало файла gg, конец файла G.  

6. Назовите и дайте краткую характеристику основным группам команд редактирования.  
Ответ: Вставка текста(i — перед курсором, a — после курсора. o — новая строка ниже, O — новая строка выше.) Удаление:(x — символ под курсором, dd — строка. dw — слово, D — до конца строки.) Копирование/вставка(yy — копировать строку, p - вставить после) Замена(r — заменить символ, cw — заменить слово)  

7. Необходимо заполнить строку символами $. Каковы ваши действия?  
Ответ: Перейти в командный режим (Esc). Ввести команду замены для текущей строки: :s/./$/g  

8. Как отменить некорректное действие, связанное с процессом редактирования?  
Ответ: Отмена последнего изменения: u (командный режим).  

9. Назовите и дайте характеристику основным группам команд режима последней строки.  
Ответ: Сохранение/выход(:w — сохранить, :q — выйти, :wq — сохранить и выйти) Поиск/замена(:/текст — поиск вперёд, :?текст — поиск назад. :%s/старый/новый/g — глобальная замена.) Настройки(:set nu — номера строк, :set nonu — убрать номера)  

10. Как определить, не перемещая курсора, позицию, в которой заканчивается строка?  
Ответ: В командном режиме нажать $ — курсор переместится в конец строки.  

11. Выполните анализ опций редактора vi (сколько их, как узнать их назначение и т.д.).  
Ответ: Просмотр всех опций(:set all) Назначение опции(:help 'опция')  

12. Как определить режим работы редактора vi?  
Ответ: Командный режим: нажатие Esc (ничего не вводится). Режим вставки: внизу экрана нет приглашения, там написано insert, значит можно вводить текст. Режим последней строки: после нажатия : появляется приглашение внизу.  

13. Постройте граф взаимосвязи режимов работы редактора vi.  
Ответ: Командный режим (Esc)  -> Режим вставки (Esc для возврата) -> Режим последней строки (Enter для выполнения ->возврат в командный). Все режимы возвращаются в командный через Esc (или выполнение команды в ex-режиме).
